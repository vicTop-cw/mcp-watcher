# mcp-watcher 项目申报书

## 1. 项目名称

mcp-watcher：MoonBit 实现的 AI 工作区自治运行时

## 2. 项目简介

mcp-watcher 把 AI 工作区里反复出现的文件治理琐事收敛为一份声明式规则，由后台常驻进程安静执行，不占用人与 Agent 的每一轮对话。运行链路为：JSON 规则（schema v1.1）→ 文件事件（native 采用 Windows ReadDirectoryChangesW 内核事件，js 采用 fs.watch）→ 两层匹配（事件与 glob、exclude 优先、条件 AND）→ 生命周期动作（TTL、trash、command、internal、mcp_tool_call）→ 结果以 JSONL 落盘。规则支持按 id 热重载，变更无需停机；动作前后各设一道门禁：guard 负责准入，acceptance 负责产物验收。项目另提供基于 SQLite FTS5 的工作区文件元数据索引与只读检索，便于 AI 快速定位文件。当前版本 0.2.3。

## 3. 项目方向与通用性

方向：MoonBit 原生库、AI 工作区自治运行时、声明式规则引擎、文件生命周期治理、后台守护进程。

通用性：本项目不绑定任何特定 AI 产品，提供的是"用声明式规则描述文件事件，再自动执行治理动作"的通用能力，可服务于 AI 工作区、CI 产物目录或个人数据目录。实现分三层解耦：规则层用 JSON DSL 描述事件、glob、条件与动作，可读可审查可版本化；事件层由 rx monitor 提供 native 与 js 双后端，统一映射为 FsEvent；动作层是带生命周期语义的操作，guard 与 acceptance 作为正交的强化维度。任一层均可独立替换或增强。

## 4. 预期使用场景

**场景一：Agent 工作区临时产物自治。** Agent 完成一轮任务后会在工作区留下大量临时文件与中间产物。常规做法是每轮对话附加一句清理指令，既消耗对话轮次，也依赖 Agent 记住执行。使用本项目时，管理员只写一条规则"create 事件命中 *.tmp → 注册 TTL → 到期进回收站"，守护进程在后台独立完成，Agent 全程无感。规则变更后自动热加载，不必重启服务。

**场景二：工作区文件快速检索。** AI 需要定位"上周修改过的 Markdown 报告"时，遍历目录既慢又占上下文。开启 index 配置后，守护进程随文件事件增量维护 SQLite FTS5 元数据索引，记录路径、类型、大小、mtime 与扩展名；调用 `search <watch_dir> --keyword "report" --ext md` 即得候选列表，结果确定性可复现。向量召回尚未实现，当前为关键词与元数据检索。

**场景三：CI 构建产物验收与回收。** 构建脚本产出文件后需要确认产物有效，无效产物应及时清理。本项目用 guard 在动作前校验命令退出码（非 0 按 skip 或 stop 处理），用 acceptance 在动作后校验 expect_exit、stdout_contains 与 artifact_glob；验收不通过时保留真实退出码与输出，触发 product.invalid 事件并交由 TTL/trash 回收流处理，不做自动重试，避免掩盖构建错误。

## 5. 拟实现的核心功能

| 模块 | 功能 |
|---|---|
| 规则 DSL | JSON 声明式规则，解析 fail-closed，支持 schema v1.1 门禁字段 |
| 事件匹配 | create/modify/delete/rename/attrib/all 与 interval 定时源；glob、exclude 优先、条件 AND |
| 生命周期动作 | TTL 到期判定与事件；trash 在 native 物理移入回收目录；command 走 argv 与显式白名单；internal 四操作；mcp_tool_call 仅 js 落地 |
| 双门禁 | guard 前置准入，acceptance 后置验收，均为纯函数判定，无重试循环 |
| 热重载 | 规则按 id 增量重挂订阅，坏 JSON 回退旧规则表 |
| 工作区索引 | native 端 SQLite FTS5 元数据索引，`search` 只读检索 |
| 可观测 | 执行记录 JSONL 落盘，status 展示索引状态 |
| CLI | validate / start / status / run / reload / search / help |

## 6. 项目性质

原创自研项目。规则 DSL、两层匹配、TTL 追踪、command 白名单、双门禁纯函数判定、cron 解析、CLI 与索引层均为本仓库实现。项目非零依赖，事件总线、文件监控与命令执行复用开源项目 RX-MBT，协程与 native 文件系统能力来自 moonbitlang/async。加密在 native 不可做实，返回可诊断错误且不写空密文；webhook 为扩展位；wasm-gc 因依赖侧符号未绑定暂未达成。
